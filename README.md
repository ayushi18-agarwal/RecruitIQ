# 🚀 RecruitIQ

### AI-Powered Recruitment Intelligence & Decision Support Platform

RecruitIQ is an AI-powered Recruitment Intelligence and Decision Support Platform built on a **Hybrid AI Architecture** that combines transformer-based NLP, traditional machine learning, and Large Language Models (LLMs) to automate candidate evaluation, ranking, interview preparation, recruiter analytics, and hiring workflows.

Unlike conventional Applicant Tracking Systems (ATS) that focus primarily on application tracking and keyword filtering, RecruitIQ leverages semantic understanding, skill-gap intelligence, recruitment analytics, workflow automation, and generative AI to help organizations make faster and more informed hiring decisions.

---

## 🎯 Project Vision

Modern recruiters spend significant time manually screening resumes, comparing candidates against job requirements, identifying skill gaps, and preparing interviews.

RecruitIQ addresses these challenges by providing:

# 🧠 Hybrid AI Architecture

RecruitIQ employs a Hybrid AI Architecture that combines traditional machine learning, transformer-based semantic understanding, and large language models to deliver accurate and explainable recruitment intelligence.

### Layer 1: Semantic Intelligence

- MiniLM (all-MiniLM-L6-v2)
- Sentence Transformers
- 384-dimensional embeddings
- Cosine Similarity Analysis

This layer understands the semantic meaning of resumes and job descriptions beyond simple keyword matching.

### Layer 2: Machine Learning Intelligence

- TF-IDF Vectorization
- Scikit-Learn Models
- Candidate Classification & Ranking

This layer provides structured feature extraction and supports candidate evaluation and ranking.

### Layer 3: Recruitment Intelligence Engine

- Skill Coverage Analysis
- Experience Validation
- ATS Score Generation
- Hiring Recommendation Classification

### Layer 4: Generative AI Layer

- LLaMA 3.3 70B (Groq API)

Generates:

- Personalized Interview Questions
- Candidate Summaries
- Skill Gap Assessments
- Recruiter Assistance

By combining semantic NLP, machine learning, and generative AI, RecruitIQ delivers a comprehensive recruitment intelligence platform rather than a traditional resume screening system.
